# habit-tracker

Трекер привычек в браузере: добавляйте привычки, отмечайте выполненные дни и смотрите текущую и рекордную серии. Без сборки и зависимостей, данные хранятся в `localStorage` вашего браузера.

## Запуск
```
python -m http.server 8000
```
и открыть http://localhost:8000 (из-за ES-модулей файл нельзя открывать двойным кликом).

## Тест логики
```
node test.mjs
```

## Как считается серия
- текущая серия — подряд идущие дни, заканчивающиеся сегодня или вчера (сегодня можно отметить позже, серия не обрывается);
- рекорд — самая длинная серия за всё время, дубли дат не учитываются.

Учебный проект для портфолио.
